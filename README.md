# Simuladão Caveira — PM, PC e PPPE

Landing page estática (HTML, CSS e JS, sem build). Publicada pela Vercel a partir da `main`.

## Preencher os locais de prova

Edite **apenas** `locais.js`. Campo vazio aparece como "A definir". Ao preencher `endereco`, o botão
"Como chegar" aparece sozinho.

## Outros ajustes

- Checkout, data da prova, fim da venda e WhatsApp: bloco `CONFIG` no começo do `script.js`.
- Horário geral e preço também aparecem escritos no `index.html` (hero, ingresso e perguntas).
- Link direto para uma cidade: `/?cidade=petrolina`.

## Domínio

Depois de definir o domínio, troque `og:image` no `index.html` pelo endereço completo e adicione `canonical`.
